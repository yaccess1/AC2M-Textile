Préparer une photo

Cet outil détoure, recadre et met à l’échelle votre photo pour qu’elle s’intègre parfaitement au configurateur. Le fichier produit porte le bon nom : il suffit de le déposer dans assets/maquettes/, sans modifier le code.

  1. Choisissez le produit, le coloris et la vue.
  2. Importez la photo, bien de face, sur fond uni ou déjà détourée.
  3. Ajustez si besoin pour que le vêtement suive les repères rouges.
  4. Téléchargez, puis déposez le fichier dans assets/maquettes/.
